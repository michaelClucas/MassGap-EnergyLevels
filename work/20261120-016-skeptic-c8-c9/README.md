## C8 verdict: survives, with rewording

**(a) Piazza-Shen. Verified.** arXiv:2610.35286, Jack Piazza and Hao Shen, "Log-Sobolev inequality for 2D SU(N) lattice gauge theory at all couplings", math.PR, 26 Oct 2026. Theorem 1.1: for every N >= 2 and every real beta there is C_{N,beta}, depending only on N and beta, such that for every L >= 1 and every smooth F on G^{E_L^+} (all functions, not only gauge-invariant ones), Ent(F^2) <= 2C sum_e int |grad_e F|^2 dmu. Lattice: the torus (Z/LZ)^2 (eq. 1.1); measure exp(N beta sum_p Re Tr U_p) times Haar; Lie algebra metric Tr(X^dag Y) (section 2). So 011's reading is right: link-gradient Dirichlet form, torus, constant uniform in L, beta_ours = 4 beta_PS for SU(2) (from exp(2 beta_PS tr U_p) = exp((beta/2) tr U_p)), metric differs from ours by a factor 2 (constant only). Remark 1.2: the method needs uniform positive Ricci curvature and does not extend to U(1). Section 7: C_LS >= c beta^{1/3} shown for SU(N) with 4 | N; SU(2) not covered. All as reported.
- Transfer: LSI with constant C gives Poincare Var(F) <= C int |grad F|^2 (standard). 007 fact 6 (gap(H_FF) = 1/4 x Poincare constant for E(f) = sum_l int |grad_l f|^2, unit S^3 metric) is consistent with the beta = 0 check: class functions of one plaquette, E = 4 int |grad f|^2, lambda_1(S^3) = 3, so gap = (1/4)(4)(3) = 3, matching the Casimir value 4 x 3/4. Constants only rescale; volume uniformity transfers. **Survives.**
- Setting caveat: (a) is SU(N) on the periodic torus; (c) is U(1) and (d) is free-boundary boxes. C8's setting line ("SU(2) and U(1)") mixes these. Free boundary for (a) remains conjectured, as 011 says.

**(b) Comparison loss 4 - 4cos(pi/(L+1)). Survives as a statement about the method only.** U(1): exact (gauge-invariant functions of F, E = grad_F f^T M grad_F f, M = 4I - A on the L x L free-boundary grid). SU(2): it is the pointwise comparison constant (infimum over configurations, approached near flat configurations). 011 uses it only to say the "product measure + pointwise comparison + tensorisation" plan cannot give volume-uniform constants; it is not claimed as a bound on the true gap (the true gap is volume-uniform on the torus by (a)). Fine. Wording should say "pointwise comparison constant".

**(c) U(1) bound. Survives.** Test function, Dirichlet form and variance re-derived: for f = sum_p v_p g(F_p) with F_p iid von Mises, E(f) = (E g')^2 v^T M v + Var(g') sum_p M_pp v_p^2 = (E g')^2 lambda_min + 4 Var(g'), Var f = Var g; gap <= (1/4)E/Var. Independent L -> infinity values: 3.2266e-1, 2.6687e-2, 1.2014e-3, 1.1938e-6, 1.2550e-10, 1.0269e-14 at beta = 2, 4, 6, 10, 15, 20, equal to 011's to 4 digits. Ratio to beta/I_0(beta)^2 is 0.95-0.97 for beta >= 6, ratio to 2 pi beta^2 e^{-2 beta} 0.92-0.96, so "~" is accurate. "Volume-uniform" means: on L x L free-boundary boxes the bound decreases to this value as L -> infinity, so no volume-uniform lower bound can exceed it. No contradiction with Piazza-Shen (their Remark 1.2 excludes U(1)) or with Bakry-Emery (U(1) has Ric = 0, so it gives nothing).

**(d) SU(2) numbers. Survive.** Single plaquette: 3.00000, 3.19966, 7.74166, 17.80084, 97.97336, 397.99366 at beta = 0, 1, 5, 10, 50, 200 (011: same to 5 digits); large-beta 2 beta - O(1) consistent with the radial degree-2 Ornstein-Uhlenbeck mode. Nested loops: E = sum_k a_k^2 4 s_k E sin^2 theta_k is right (only the 4 s_k links of the k-th boundary move W_k, each isometrically; boundaries disjoint, so no cross terms); moment formulas checked (Bessel ratios agree with quadrature to 3e-15). Rayleigh quotients of explicit vectors in 80-digit arithmetic: 3.0000 (beta 0), 3.9929 (2), 10.3264 (10), 12.9110 (20), 15.6956 (100), 16.3851 (500), 16.4752 (1000, s_max = 201), identical to `run_D.log`. So 16.5 is a legitimate upper bound on gap(H_FF) for every free-boundary box of side >= 201 at those beta. Two qualifications: it was evaluated at sampled beta (2, 5, ..., 1000), not proved for all beta <= 1000; and it relies on the 2D lasso independence of plaquette holonomies on free-boundary boxes (cited, standard, not re-proved here). Theta(1) as beta -> infinity remains a conjecture.

## C9 verdict: survives, with three wording fixes

**Flux sectors. Correct and complete.** Cuts {x(0,0), x(0,1)} and {y(0,0), y(1,0)}; each plaquette meets each cut in 0 or 2 links (checked), so Tr U_p preserves both parities; Gauss's law makes them cut-independent; the four (fx, fy) classes partition the gauge-invariant space. These are the Z2 electric ('t Hooft) flux sectors of SU(2) on T^2. Nonzero-flux states are physical in the KS Hilbert space (invariant under all periodic gauge transformations), so including them in Delta_all is correct.

**Momentum blocking.** Not rebuilt (RAM). `validate.log`: union of k-block spectra equals full-sector spectrum to 4e-14 in all four sectors at j_max = 1; Tx, Ty, sigma_x, sigma_d, rot90 orthogonal and commuting with W to 2e-15; (0,1) = (1,0) spectra at j_max = 3/2. P, Q, the shell and the floor are translation invariant, so the per-block Schur Lemma is valid. Accepted.

**Split floor. Proof correct.** Line by line: (i) on the 2x2 torus every link lies in exactly two distinct plaquettes and each plaquette has 4 distinct links and 4 distinct corners (checked), so sum_p t(g^2/4) sum_{l in p} C_l = t(g^2/2) sum_l C_l; (ii) Q commutes with the Casimirs, so (1-t)(g^2/2) sum C >= (1-t)(g^2/2) c_Q on Q; (iii) <psi, h_p psi> >= inf spec h_p for any psi, no need for h_p to preserve Q; (iv) e^{-s h_p} is positivity improving on L^2(SU(2)^4) (heat kernel times bounded potential, Trotter), so the ground state is unique and positive; the corner gauge group acts by measure-preserving translations, so the ground state is invariant, hence a class function of U_p (gauge-fix three links); (v) on chi_j(U_p) each of the four link Laplacians gives j(j+1) (including the reversed link), and chi_{1/2} chi_j = chi_{j-1/2} + chi_{j+1/2} gives off-diagonal -2/g^2. Independent numbers: c_Q = 11 (max spin >= 2) and 7.5 (max spin >= 3/2), minimum over all flux sectors, as used (per sector: 11/12/12/12 and 8/7.5/7.5/8, so using the global minimum is conservative). My dense split floors are 5e-4 or less above the `results.csv` d values at every g^2 (e.g. 12.04633 vs 12.04583 at g^2 = 3, c_Q = 11), consistent with 012 using a coarser t grid and a certified (lower) tail bound. No issue.

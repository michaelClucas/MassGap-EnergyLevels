# data/

Lattice glueball spectra and string-tension scales for pure SU(N) Yang-Mills, transcribed from the
authors' arXiv LaTeX source. Provenance, table numbers and conventions for every file are in
`SOURCES.md`.

All CSVs are generated by `work/20261120-002-glueball-data/extract_tables.py`, which parses the
LaTeX tables directly (no numbers typed by hand). To regenerate: download each e-print from
`https://arxiv.org/e-print/<id>`, unpack into `<SRC>/<id with / replaced by _>/`, then run
`python work/20261120-002-glueball-data/extract_tables.py <SRC> data` from the repo root.

## Schema (one row = one number from one table cell)

| column | meaning |
|---|---|
| `source_id` | MP1999, Chen2006, AT2020, LTW2004, AT2021, Teper1998, AT2016 (see SOURCES.md) |
| `N` | gauge group SU(N); `inf` = authors' large-N extrapolation |
| `dim` | spacetime dimension: 4 = 3+1D, 3 = 2+1D |
| `JPC` | continuum J^PC, e.g. `0++`, `2-+`. Empty for scale-setting rows |
| `quantity` | `m/sqrt_sigma`, `m/sqrt_sigma_lower_bound` (value is a lower bound), `r0*m`, `m` (physical units), `m/m(0++)`, `m/m(2++)`, `m/g2N`, `sqrt_sigma/g2N`, `r0*sqrt_sigma`, `r0`, `1/r0`, `sqrt_sigma` |
| `value` | central value, as printed (string precision preserved) |
| `err_stat` | first quoted error; its meaning per table is in `note` / SOURCES.md. Converted from parenthesis notation: `4.21(11)` -> 0.11, `7.6(44)` -> 4.4, `1.7(1.5)` -> 1.5 |
| `err_sys` | second quoted error if the table gives one, else empty |
| `units` | `dimensionless`, `MeV`, `GeV`, `fm` |
| `table` | table number in LaTeX float order of the arXiv source, plus the LaTeX `\label` |
| `level` | 0 = ground state in that J^PC channel, 1 = first excitation, ... (as labelled by the authors: `*`, `ex1`, or row order) |
| `row_label` | the row/column label as it appears in the source, for audit |
| `note` | author fit-quality marks, fit ranges, error meanings, transcription remarks |

Everything here is a lattice Monte Carlo result extrapolated to the continuum (and, for `N=inf`,
to large N) by the cited authors. These are observations with errors, not theorems.
